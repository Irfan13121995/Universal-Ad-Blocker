Whole-Home Network Router Configuration
To protect every device on your Wi-Fi/Ethernet (phones, smart TVs, laptops, tablets), configure your router's DHCP DNS.

This Windows 11 host is currently reachable on your local LAN at: Scanning...

  1. Log in to your home router admin portal (typically http://192.168.1.1 or http://192.168.0.1).
  2. Navigate to Network / LAN / DHCP Server Settings.
  3. Locate the Primary DNS Server field and set it to this Windows PC's static LAN IP address (shown above).
  4. Leave Secondary DNS blank (or point it to this machine's IP as well) so devices don't bypass your sinkhole.
  5. Ensure the Windows Firewall allows incoming UDP & TCP on Port 53 (run scripts/Setup-Firewall.ps1).
  6. Save router settings. Connected devices will now automatically filter ads through this Windows 11 sinkhole!
