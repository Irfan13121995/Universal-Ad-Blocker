Whole-Home Router & Smart TV DNS Configuration
Block Smart TV home-screen banners, Samsung ACR telemetry, Google TV launcher ads, and app trackers across your entire Wi-Fi.

Option 1: Wi-Fi Router DHCP (Recommended — Protects All TVs)
  1. Open your router admin page or Deco/Mesh app (typically http://192.168.68.1 or http://192.168.1.1).
  2. Go to Advanced > IPv4 / DHCP Server > DNS Server.
  3. Set Primary DNS to 192.168.68.51 and leave Secondary DNS blank (or also 192.168.68.51).
  4. Save & reconnect TV Wi-Fi once.
Option 2A: Google TV / Android TV (Per-TV DNS)
  1. Open Settings ⚙️ > Network & Internet and select your Wi-Fi network.
  2. Select IP settings > Static.
  3. Keep your TV's current IP & Gateway (e.g. 192.168.68.1), prefix length 22 (or 24).
  4. Set DNS 1 and DNS 2 both to 192.168.68.51.
Option 2B: Samsung Smart TV — Tizen OS (Per-TV DNS)
  1. Open Settings ⚙️ > All Settings > Connection > Network > Network Status.
  2. Click IP Settings > DNS Setting > select Enter manually.
  3. Enter DNS Server: 192.168.68.51 and press OK.
  4. Pair YouTube in the YouTube & TV Shield tab to also skip in-stream YouTube video ads!

Desktop Browser YouTube Shield & Video Ad Defusal
Deep payload interception that strips video prerolls, midrolls, and promotions from YouTube across Chrome, Brave, Edge, and Firefox on Windows 11.
How YouTube Ad Defusal Works (Desktop vs Mobile)

1. Windows 11 Browsers (Chrome, Edge, Firefox, Brave): When the 1-Click Shield is active, Windows routes browser web traffic through the local proxy (127.0.0.1:8080) using your trusted local CA. Outbound QUIC (UDP 443) is blocked so browsers cannot bypass the proxy. Player API payloads are sanitized and the early scriptlet auto-skips any server-stitched ad breaks.

2. Zero Playback Buffering: Video streams (*.googlevideo.com/videoplayback) pass through a direct, zero-copy TCP tunnel. The proxy never re-encodes media chunks, preserving full 4K/60fps and 8K HDR throughput.

3. Android Mobile Protection: Private DNS (DoT) blocks all tracker and banner domains. For video ads on Android: the native YouTube app hardcodes SSL pinning (rejecting custom CAs); to enjoy 100% ad-free YouTube videos on Android, watch via mobile browsers (Chrome/Brave/Firefox) connected to Sinkhole or use the companion web shell.
